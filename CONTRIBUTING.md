# Contributing to temetro landing page

Thanks for your interest in contributing! This repo is the marketing landing page for [temetro](https://github.com/temetro/temetro).

## Getting started

1. Fork the repository and create a branch from `main`.
2. Install dependencies: `npm install`
3. Start the dev server: `npm run dev` (runs on `localhost:3000`)
4. Make your changes and open a pull request.

## What lives here

This is a Next.js app containing the public-facing marketing site — copy, visuals, and landing components. Product functionality lives in the [main monorepo](https://github.com/temetro/temetro).

## Code style

- TypeScript throughout
- Tailwind for styling — follow the existing design tokens
- No comments unless the *why* is non-obvious

## Reporting bugs

Use the [bug report template](.github/ISSUE_TEMPLATE/bug_report.md). Include a screenshot if it's a visual issue.

## Security issues

Do **not** open a public issue for security vulnerabilities. See [SECURITY.md](SECURITY.md).
